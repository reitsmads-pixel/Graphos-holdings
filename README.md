# Graphos Holdings — Company Website

Static website for **Graphos Holdings**, the company behind Afripraat and Educlicklab. Built for company/developer validation (e.g. Apple Developer Program enrollment).

## Structure

- `index.html` — main page (about, products, contact)
- `privacy.html` — privacy policy
- `assets/logo.svg` — Graphos Holdings logo

## Hosting with GitHub Pages

1. Merge this branch into `main`.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. The site will be published at `https://reitsmads-pixel.github.io/Graphos-holdings/`.

To use a custom domain (recommended for Apple validation), add it under **Settings → Pages → Custom domain** and point your DNS at GitHub Pages.
